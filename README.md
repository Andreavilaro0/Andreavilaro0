### Featured project

**[Clara — civicaid-voice](https://github.com/Andreavilaro0/civicaid-voice)** — A voice-first
assistant on WhatsApp and the web that helps people in Spain with public services and paperwork.
It works with text, voice and images in 8 languages: when you send a voice note, it detects the
language and answers with audio in the same language.
I built it as the **sole developer** in 48 hours at the OdiseIA4Good 2026 hackathon
(300+ participants).
[Live demo](https://andreavilaro0.github.io/civicaid-voice/)
`Python` `Flask` `Gemini` `ElevenLabs` `React` `TypeScript` `Docker`

### Other projects

**[helios_deck](https://github.com/Andreavilaro0/helios_deck)** — A space-weather dashboard.
It downloads live data from NOAA (Kp index, solar wind speed, X-ray and proton flux), stores it in
SQLite and renders it on the server. Every number is a real measurement.
`TypeScript` `React Router` `SQLite` `Three.js` `Vitest` `Docker`

**[udit-pixelforge](https://github.com/Andreavilaro0/udit-pixelforge)** — A custom live Linux
distribution (Debian 13, ARM64) with its own theme and an interactive terminal menu. Built with
Iván Herrera for an Advanced Operating Systems course. The README explains the boot and kernel
problems we found and how we fixed them.
`Linux` `Debian` `Bash` `QEMU`

**[Proyecto-libreria](https://github.com/Andreavilaro0/Proyecto-libreria)** — A library
management system for the terminal in C++17: items, users and loans, saved in CSV files.
`C++17` `CMake`
